# Causality and Provenance

Every disruption-caused breach receives a trace from disruption to purchase
order, shortage, production order, customer line, and revenue exposure.
Edges carry the rule that produced the relationship.

Headline metrics include rule ID and version, source record IDs, calculation
step IDs, scenario ID, impact run ID, input state hash, timestamp, and data
quality status. Pre-existing, unrelated, disruption-caused, worsened, and
insufficient-evidence attribution remain distinct.
