# Impact Rule Catalogue

Rule set: `impact-rules-v1.0.0`  
Dataset compatibility: `1.0.0`

The registry currently covers effective-state selection (`STATE-001`),
information-time selection (`STATE-002`), outstanding quantity (`SUP-001`),
disrupted arrival (`SUP-004`), affected purchase orders (`SUP-005`),
projected receipt quantity (`SUP-006`), and state completeness (`DQ-001`).
Each rule declares inputs, outputs, units, rounding, formula, and failure
conditions in `config/rules/impact-rules-v1.0.0.yaml`.
