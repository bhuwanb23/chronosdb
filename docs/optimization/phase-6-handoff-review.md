# Phase 6 Handoff Review

Phase 7 operates only on validated Phase 6 simulation outputs.

## Required Inputs

- Do-Nothing Scenario
- Transfer Scenario
- Expedite Scenario
- Alternate Supplier Scenario
- Reschedule Scenario
- Hybrid Scenario

Each must include:

- Result Hash
- Revenue Risk
- Delay
- Breaches
- Cost
- Warnings
- Feasibility Metadata
- Provenance

## Validation Checks

- Scenario hashes valid
- Simulation completed
- Metrics available
- Rule versions consistent
- Candidate count >= 2

## Exit Gate

Optimization cannot run on unvalidated or incomplete simulation outputs.
