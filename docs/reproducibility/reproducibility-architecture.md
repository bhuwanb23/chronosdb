# Phase 15B: Reproducibility Architecture

## Phase 15 Deep Dive: Packaging and Reproducibility

### Core Principle
Everything demonstrated must be reproducible.

### Reproducible
- Schema
- Dataset
- Evidence Store
- Embeddings
- Benchmarks
- Golden Scenario
- UI State

### Not Reproducible
- Manual database edits
- Private scripts
- Developer-only files
- Hidden credentials

### Reproducibility Layers
1. **Environment** (Phase 15C)
2. **Database** (Phase 15F)
3. **Data** (Phase 15H)
4. **Models** (Phase 15I)
5. **Services** (Phase 15J)
6. **Benchmarks** (Phase 13)
7. **UI** (Phase 12)
