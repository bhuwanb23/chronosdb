# Phase 3M–3O: Benchmarks and Fixtures

The benchmark suite contains 60 scenarios across supplier outages, transfer and
alternate-supply constraints, no-impact, no-feasible, insufficient-data, and
tie/Pareto cases. Difficulty levels are assigned deterministically. Expected
outputs preserve an optimal set when a unique recommendation is not justified.

Thirty Phase 3O fixtures cover invalid references and quantities, temporal
boundaries, missing critical data, contradictory state, hard-constraint traps,
and unauthorized evidence. Each fixture has a stable ID and expected error
label; fixture inputs are never mixed into ordinary generated records.
