# Phase 7 Handoff Review

Phase 8 operates on validated optimization outputs.

## Required Inputs

- Optimization Results
- Candidate Rankings
- Recommendation Package
- Utility Scores
- Constraint Results
- Decision Provenance
- Simulation References

## Validation Checks

- Recommendation exists
- Scenario ID exists
- Result hashes exist
- Optimization run exists
- Audit references valid
- Evidence package not yet created

## Exit Gate

Evidence retrieval cannot run on unvalidated optimization outputs.
