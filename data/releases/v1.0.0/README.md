# ChronosDB Synthetic Dataset v1.0.0

This is a fictional, project-authored supply-chain dataset for deterministic demonstration, validation, and benchmark evaluation. Suppliers, customers, prices, incidents, and outcomes are synthetic and are not commercial forecasts.

The canonical demo release is accompanied by tiny, standard, and stress profiles. Use `manifest.json`, `checksums.sha256`, and `load-order.json` for loading.
